# 小红书敏感词替换库

> **使用方式**：Step 6c 生成 `xiaohongshu-post.md` 后，对照本库逐词替换。
> 用户每期提供小红书发布截图反馈时，将新发现的限流词追加到本库。

## 替换规则

1. **中文同义改写**（首选）：用不触发限流的中文近义表达，保持文案自然流畅
2. **英文替代**（次选）：用英文替换，但必须首字母大写（Data Center 而非 data center），避免像占位符
3. **Unicode 数学字体**（末选）：英文本身也敏感时用 `𝙈𝙖𝙩𝙝 𝙁𝙤𝙣𝙩`

**⚠️ 优先使用中文同义词**——生硬地插入英文会破坏编辑调性。只有当中文无论怎么改写都绕不开敏感词时，才退而用英文。英文替代词必须正确大写。

## 话题聚类风险词（非单词限流，整条新闻因话题被降权或剔除）

这些词/主题单独替换**无效**，因为限流基于话题识别，而非词匹配。
应该在 score-engine `classifyTopic()` 阶段处理（自动降权或硬剔除），
curation 阶段再应用 curation-framework.md 的「话题配额」二次把关。

- 台独 / 港独 / 疆独 / 藏独 / 涉疆
- 台湾独立 / 西藏独立

**处理**：score-engine 的 SOVEREIGNTY 正则命中后 adjustment=-20，total 落入负分区间，curation 阶段整条跳过。
