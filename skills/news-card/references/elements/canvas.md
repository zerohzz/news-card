# 画布与页面系统

## 画布规格

| 属性 | 值 | 说明 |
|------|---|------|
| 逻辑尺寸 | 1080×1920px | 9:16 竖版，XHS 原生比例 |
| 截图尺寸 | 2160×3840px | @2x Retina 输出 |
| 视口 | 1080×1920px | 硬编码，不可配置 |
| 截图工具 | Playwright Chromium | 自动检测 `~/.cache/ms-playwright/` |

**Default**: 所有 10 张卡片统一 9:16，包括封面。

## 安全区

XHS 移动端会在特定区域叠加 UI 元素，内容必须避开：

```
┌─────────────────────────────┐
│                             │  ← top 280px: 封面品牌区保留
│                             │
│                             │
│      ✓ 3:4 安全内容区       │  ← 中央 810×1440px
│      （内容集中在此）        │
│                             │
│                             │
│  [XHS 标题栏 / 互动按钮]    │  ← bottom 240px: 避免关键信息
└─────────────────────────────┘
```

| 安全区 | 位置 | 原因 |
|--------|------|------|
| top-padding | 顶部 280px | 封面品牌区 / 系统状态栏 |
| bottom-padding | 底部 240px | XHS 标题栏、互动按钮覆盖 |
| center-safe | 中央 3:4 区域 | XHS 缩略图裁切不会裁掉此区域 |

> Hero Cover (P0) 的内容全部位于中央 3:4 安全区内（280px top / 240px bottom padding），确保 XHS 缩略图永远不会裁切到内容。

## 页面类型

10 张卡片分为 5 种页面类型：

### Hero Cover（P0）

品牌封面，开放式布局。**不受 50–65% 密度规则约束**——这是编辑品牌钩子页。

布局（自上而下，在 3:4 安全区内）：
1. **日期** — `2026.03.30 Mon` 格式，40px，logo 上方
2. **品牌标识** — SVG 双弧圆 + `zz`（金色，Noto Serif SC 900）+ `AI每日资讯`（黑色）
3. **Slogan** — 2 行，绿/红高亮：`每天阅读N分钟 / 节约N小时无效刷新 · $X 费用`
4. **分隔线** — 双线
5. **统计栏** — `精选N条 | M+条候选 | P+个来源`（紧凑，次要）
6. **Top 4 新闻** — tier-1 标题（34px）+ 分类徽章 + 来源

### Menu / 目录（P1）

24 条新闻索引，按 category 色块分组。

### Feature 整页（P2–P5）

每页 1 条 tier-1 新闻，整页展示。包含 `content_html` 富内容。
- 内容区可用高度 ~1100px（1920px - 标题区 ~320px - 页脚区 ~150px - 内边距 ~350px）

### Half-page 半页（P6–P7）

每页 2 条 tier-2 新闻，上下分区。

### Briefs 网格（P8–P9）

2×4 网格，每页 8 条 tier-3 新闻。
- P8: 快讯速览（来自 scored-news.json）
- P9: 研究前沿 / Builder 动态（来自 scored-signals.json）
- 每张卡片高度约 400px，标题 2 行 + 摘要 5 行是上限

## 页码规则

| 页面 | 页码显示 |
|------|---------|
| Hero Cover (P0) | **不显示** |
| 内容页 (P1–P9) | `X / 9`，共 9 页 |
