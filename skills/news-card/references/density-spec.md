# 信息密度准则（强制）

> **核心原则：「填满」以人眼阅读感受为标准，不以 DOM 元素是否存在为标准。**

---

## 各页面类型最低文字占比

| 页面类型 | 文字内容最低占比 | 具体要求 |
|---------|---------------|---------|
| 封面 | 60% | 16 条新闻标题全部可见，色块内必须有文字 |
| 第一梯队 | 55% | 标题 + 150 字摘要 + 来源 + 分类标签 + 亮点区 |
| 第二梯队半页 | 50% | 标题 + 80 字摘要 + 来源（×2 条） |
| 快讯页 | 65% | 8 个方框卡片，每个有标题（≤25字） + 60–90 字摘要（硬上限 90 字） + 来源 |

---

## 禁止的留白模式

- **大色块空洞**：一个色块内文字面积不足色块面积的 40% → 不合格
- **底部大空白**：页面底部空白超过总高度的 10%（192px） → 不合格
- **过大间距**：卡片间距 > 24px（在 1080px 宽度下） → 不合格
- **元素过大**：单个装饰元素占据 > 30% 页面高度 → 不合格
- **标题孤立**：标题下方无正文内容直接接下一个标题 → 不合格

---

## 间距规则

| 间距类型 | 数值 |
|---------|------|
| 段落间距 | 28px (margin-bottom) |
| 区块间距 | 36px (divider + margin) |
| 卡片内边距 | 20-24px |
| 页面左右边距 | 60px |
| 页面上边距 | 48px |
| 页面下边距 | 36px |
| 快讯 grid gap | 12px |
| 半页 stories gap | 0 (用 border-top 分隔) |

---

## 必须的填充策略

- **摘要补充**：如果摘要不够长，补充关键数据点、原文要点、或技术细节
- **快讯网格**：8 个卡片使用 2×4 网格，充分利用 1080px 宽度
- **页脚信息条**：每页底部固定放置日期 + 期号 + 品牌水印条（高度 60–80px）
- **分类标签**：每条新闻必须有分类色块标签，颜色对应 design-tokens.md
- **来源标注**：每条新闻必须标注来源名称

---

## 各页面类型内容检查清单

### 封面页
- [ ] 日期和期号清晰可见
- [ ] 所有 16 条标题可读（字号 ≥ 16px）
- [ ] 按 category 分组，每组有对应色块
- [ ] 色块内有文字，不存在纯色空块
- [ ] 页面无大面积空白

### 第一梯队页（×4）
- [ ] 标题 ≥ 40px
- [ ] 中文摘要 ≥ 150 字
- [ ] 分类色块标签
- [ ] 来源 + 链接
- [ ] 亮点数据区域
- [ ] 页面底部信息条
- [ ] 文字内容占页面 ≥ 55%

### 第二梯队页（×2，每页 2 条）
- [ ] 每条标题 ≥ 28px
- [ ] 每条摘要 ≥ 80 字
- [ ] 两条之间有清晰分隔
- [ ] 分类色块标签
- [ ] 来源标注
- [ ] 页面底部信息条
- [ ] 文字内容占页面 ≥ 50%

### 快讯页
- [ ] 2×4 网格布局
- [ ] 每个卡片有标题（≤25字）+ 60–90 字摘要（硬上限 90 字）+ 来源
- [ ] 卡片间距 ≤ 24px
- [ ] 每个卡片有 category 色块边框或标签
- [ ] 页面底部信息条
- [ ] 文字内容占页面 ≥ 65%
