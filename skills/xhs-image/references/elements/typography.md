## Text Hierarchy

| Level | Relative Size | Use |
|-------|--------------|-----|
| H1 | 100% | Main title, single per image |
| H2 | 65-75% | Section headers |
| H3 | 50-60% | Sub-sections |
| Body | 40-50% | Main content text |
| Caption | 30-35% | Small notes, sources |

## Language Considerations

### Chinese Text
- Use Chinese quotation marks: ""（）！？
- Character spacing: slightly wider (letter-spacing: 0.05em)
- Line height: 1.5-1.8x for readability
- Punctuation: avoid line-start for 。，！？）

### Mixed Chinese-English
- English words may use different font weight
- Numbers typically rendered in English style
- Brand names keep original language

## Style-Specific Typography

### Cute
- Rounded, bubbly lettering
- Soft shadows, playful decorations
- Pastel color accents

### Notion
- Clean hand-drawn lettering
- Simple labels, minimal decoration
- Black/gray primary colors

### Bold
- Heavy weight, high contrast
- 3D shadows or stroke effects
- Large, commanding sizes

### Chalkboard
- Chalk texture on all text
- Imperfect baselines
- Visible texture and dust
