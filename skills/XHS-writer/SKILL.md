# 小红书爆款笔记创作

将主题或素材转化为符合小红书平台调性的高互动笔记。输出包含标题方案、完整正文、SEO标签和配图指导。

## 核心原则

- **像朋友聊天，不像写文章** —— 小红书的本质是"分享"，不是"发表"。语气要亲切、自然、有人味儿
- **先提供价值，再自然植入** —— 前70%聚焦用户痛点和解决方案，后30%可以软性引入推荐
- **真实感 > 完美感** —— 适度暴露小缺点反而增加可信度，"糙而真实"胜过"精修但假"
- **干货密度要高** —— 用户收藏的核心驱动力是"以后用得上"，每段都要有信息增量

## 创作流程

### 第一步：确认需求

从用户输入中提取以下信息（已提供的直接使用，缺失的合理推断，不要逐条追问）：

| 要素 | 说明 | 默认值 |
|------|------|--------|
| 主题/素材 | 用户想写什么 | — |
| 笔记类型 | 种草/测评/教程/攻略/观点/日常分享 | 根据主题推断 |
| 目标受众 | 人群画像 | 根据主题推断 |
| 调性 | 活泼俏皮/理性专业/温暖治愈/犀利真实 | 根据类型推断 |

如果主题足够明确，直接进入创作，不要浪费一轮对话来"确认需求"。

### 第二步：内容构思（内在思考，不展示给用户）

动笔前完成以下6个维度的系统思考。这个过程决定内容质量，但不需要输出分析报告：

**1. 核心价值点**
这篇笔记给读者的核心收获是什么？用一句话说清。如果说不清，说明还没想透。

**2. 情绪锚点**
读者在阅读过程中会被什么情绪击中？提前设计1-2个关键时刻：
- 共鸣感："这说的不就是我吗"
- 获得感："学到了，马上去试"
- 好奇心："接下来呢？"
- 优越感："原来我的选择是对的"
- 紧迫感："不赶紧就来不及了"

**3. 说服路径**
选择最适合主题的说服策略组合：
- 亲身经历（增强真实感）
- 数据/对比（增强说服力）
- 场景描写（增强代入感）
- 权威背书（增强可信度）
- 社会认同（"大家都在用"）

**4. 金句设计**
准备2-3个记忆锚点——读者最可能截图或记住的句子。好金句的特征：表达精准、有节奏感、能脱离上下文独立传播。

**5. 互动钩子**
设计让读者忍不住回应的互动点（用于结尾或正文中间）：
- 开放式提问："你们遇到过吗？"
- 选择式互动："A还是B？评论区告诉我"
- 填空式互动："用一个词形容___，我先来"
- 经验征集："有更好的方法吗？评论区教教我"
- 轻争议立场：抛出有讨论空间的观点

**6. SEO关键词**
提前规划3-5个核心关键词，确保标题和正文自然包含。关键词要覆盖：用户搜索词 + 品类词 + 场景词。

### 第三步：标题创作

生成 **5个标题方案**，每个标题标注策略类型。

#### 标题规范
- **字数**：硬上限 20 字（含标点和 emoji，平台会截断超出部分）。最佳区间 15-18 字
- **关键词前置**：核心关键词尽量出现在标题前半段
- **emoji点缀**：开头或中间可用1-2个emoji增加辨识度
- **标点节奏**：善用 ！、｜、？ 营造情绪
- **禁止套话标题**：不要用每天都能复用的通用 slogan 做标题，如「四条重磅」「3分钟看完」「今日速览」「重磅合集」等。标题必须体现当天独有的具体新闻内容，让读者一眼知道今天发生了什么

#### 标题公式库

| 公式 | 模式 | 示例 |
|------|------|------|
| 痛点型 | X%的人不知道+真相 | "90%的人防晒都白涂了！皮肤科医生说的" |
| 数据型 | 数字+效果+限定 | "坚持30天早起5点｜我的人生开了挂" |
| 身份型 | 身份标签+场景+方案 | "早八打工人｜3分钟搞定通勤妆" |
| 反常识型 | 颠覆认知+悬念 | "越贵的护肤品越伤脸？成分党看完沉默了" |
| 清单型 | N个/N款+品类+修饰 | "私藏6款平价香水｜同事以为我用的大牌" |
| 对比型 | A vs B / 前后对比 | "用了3年的厨房好物 vs 翻车的智商税" |
| 情绪型 | 强情绪词+核心信息 | "救命！这个冷门小城也太好逛了吧" |
| 利益型 | 行动+明确收益 | "学会这5点Excel技巧｜老板直接给我加薪" |

#### 二极管标题法（正负刺激）
- **正面刺激**：方法/产品 + 短期投入 + 逆天效果
- **负面刺激**：你不XXX + 绝对会后悔 + 紧迫感

#### 输出格式
```
1. [标题] — 策略：痛点型
2. [标题] — 策略：数据型
3. [标题] — 策略：身份型
4. [标题] — 策略：反常识型
5. [标题] — 策略：情绪型
```

### 第四步：正文创作

#### 整体规范
- **字数**：300-800字（最佳区间500-600字）
- **段落**：每段2-3句，段间空行，手机阅读友好
- **emoji**：每段开头用emoji做段落标记，正文中间适度点缀，不过度堆砌
- **口语化**：像跟朋友发微信一样说话，不要书面腔
- **分点清晰**：干货部分善用编号或emoji分点，方便扫读和收藏
- **不使用加粗**：小红书平台不支持 Markdown 加粗语法，正文中不要使用 `**加粗**`

#### 正文结构模板

根据笔记类型选择最合适的结构：

**种草/推荐类 — SCQA结构**
```
开头：场景/痛点引入（2-3句，制造共鸣）
冲突：为什么现有方案不够好（1-2句）
方案：推荐内容的核心亮点（主体，分点展开）
结尾：使用感受 + 互动引导
```

**测评/对比类 — 红黑榜结构**
```
开头：测评动机和背景（为什么测这个）
主体：逐项对比（外观/效果/价格/使用感受）
总结：明确推荐/避雷结论
结尾：征集读者使用经验
```

**教程/干货类 — 步骤清单结构**
```
开头：成果展示或痛点引入（先给甜头）
主体：分步骤/分要点展开（编号清晰，每步配说明）
总结：注意事项或常见误区
结尾：鼓励尝试 + 互动引导
```

**攻略类 — 信息整合结构**
```
开头：攻略适用场景和人群
主体：按维度分类（时间线/区域/价格档）
亮点：隐藏玩法或冷门推荐（彩蛋感）
结尾：收藏提醒 + 互动引导
```

**观点/感悟类 — 故事+洞察结构**
```
开头：反直觉的观点或触发事件（抓注意力）
主体：论述展开（个人经历 + 思考 + 案例）
高潮：核心金句（最强表达）
结尾：开放式问题引发讨论
```

#### 语言风格要求

**该用的词**：
- 语气词：真的、绝了、离谱（适度使用，不堆砌）
- 程度词：超推荐、真心建议、亲测有效
- 口头禅：就是说、懂的都懂

**不该用的词（额外）**：
- 过度亲昵称呼：姐妹们、家人们、宝子们、集美们（显得不专业且尴尬）
- 夸张网络用语：救命、笑死、爱了、蹲一个、巨好用（过度使用降低可信度）

**不该用的词**：
- 书面腔：综上所述、不言而喻、由此可见、首先其次最后
- 广告腔：品质卓越、匠心打造、引领潮流、震撼来袭
- 绝对化：最好的、第一、无敌（平台合规风险）
- AI味：值得一提的是、需要注意的是、总的来说

**八、AI味句式模板** 🟠 AI检测

「在…的背景下」「随着…的发展」「这不仅…更…」「无论是…还是…」「值得关注的是」「一方面…另一方面…」「不仅如此」「除此之外」

**九、书面僵化结构** 🟠 AI检测

首先/其次/最后（刚性三段式枚举）、由此可见、鉴于此、就目前而言、综上所述、基于以上分析

**十、AI 结构特征**（无具体词汇，但会触发检测） 🟠 AI检测

- 连续 3 句以上等长句子
- 完美并列（每段结构相同、每个列表项长度相同）
- 过度工整的分号分隔
- 全文无任何口语化表达或主观判断
- 段落之间全部用逻辑连接词衔接，无跳跃

**节奏控制**：
- 短句为主，偶尔长句拉节奏
- 关键信息独立成段增强冲击力
- 适当使用省略号…制造停顿感
- 感叹号用来强化情绪，但不要每句都用

#### 反 AI 检测写作策略

小红书平台会检测 AI 生成内容并限流。以下策略帮助输出更自然的文本：

- **句长变化**：刻意混合 5 字短句和 25 字长句。连续三个等长句子是 AI 最明显的特征
- **不完美感**：偶尔用省略号、破折号、或不完整的句子片段——真人写作不会每句都语法完美
- **具体细节**：用具体的时间、地点、场景代替泛泛而论。「上周三试了一下」比「近期使用后」更像人写的
- **不对称展开**：列举 3 个东西时，给其中 1 个明显更多的篇幅。AI 倾向于平均分配
- **口语连接词**：用左列，不用右列

| ✅ 用这些 | ❌ 不用这些 |
|-----------|-----------|
| 然后 | 随后 |
| 其实 | 事实上 |
| 说白了 | 换言之 |
| 不过 | 然而 |
| 反正 | 总而言之 |
| 说真的 | 坦率地说 |

- **避免完美并列**：连续段落不要用相同句式开头。如果上一段以「这个…」开头，下一段换个方式
- **插入个人判断**：「我觉得」「亲测下来」「说实话」这类主观标记是人类写作的天然防伪标签

### 第五步：标签与SEO

在正文末尾生成5-10个标签：

```
#核心关键词 #品类词 #场景词 #人群词 #热门话题词
```

标签策略：
- 前3个：高搜索量的品类大词（如 #护肤 #穿搭 #美食）
- 中间：精准场景词（如 #通勤穿搭 #学生党护肤）
- 最后：长尾词或热门话题（如 #2025必买清单）

## 不同笔记类型的创作要点速查

| 类型 | 核心驱动力 | 开头策略 | 关键要素 |
|------|-----------|---------|---------|
| 种草 | 让人心动并行动 | 场景痛点 → 解决方案 | 真实使用感受、具体细节、小缺点增加可信度 |
| 测评 | 帮人做消费决策 | 测评动机（为什么买这么多） | 多维度对比、明确结论、测评成本展示 |
| 教程 | 降低学习门槛 | 成果展示（先看到效果） | 步骤编号、每步可操作、常见踩坑 |
| 攻略 | 节省搜索时间 | 适用人群 + 总览 | 信息密度高、结构清晰、隐藏彩蛋 |
| 观点 | 引发共鸣或讨论 | 反直觉事实或个人故事 | 鲜明立场、金句、留讨论空间 |
| 日常 | 真实感和陪伴感 | 生活片段切入 | 细节感、情绪真实、不刻意升华 |

## 平台合规提醒

创作时自动规避以下风险：

**基础合规（违反会被删帖/限流）：**
- 不使用绝对化用语（最、第一、唯一、100%、NO.1、史上最、全网最）
- 功效类表述加「个人感受」「亲测」等限定
- 不编造使用时长、数据、效果
- 医疗/医美/食品类内容不做疗效承诺（禁用：治疗、根治、药效、疗效）
- 推广内容标注「合作」或在正文中自然说明
- 不包含任何外部平台引流信息（微信号、链接、二维码、淘宝搜索词）
- 不使用诱导互动话术（点赞、收藏、关注、双击、评论区见）

**反 AI 检测合规（违反会被判定为 AI 内容并限流）：**
- 不使用上方「限流词 & 敏感词速查表」中标记为 AI检测 的所有词汇和句式
- 确保句式长度有明显变化，避免机械的等长句并列
- 每段开头使用不同的句式结构
- 包含至少 2-3 处主观判断或个人视角的表达

## 质量自检清单

输出前确认：
- [ ] 标题 ≤20 字（硬上限，含标点和emoji），包含核心关键词
- [ ] 开头3句能抓住注意力
- [ ] 每段都有信息增量，没有废话
- [ ] emoji使用得当，不过度也不缺失
- [ ] 口语化自然，没有书面腔和AI味
- [ ] 结尾有互动引导，降低回复门槛
- [ ] 标签5-10个，覆盖大词+精准词
- [ ] 正文自然包含SEO关键词（不堆砌）
- [ ] 无绝对化用语和合规风险
